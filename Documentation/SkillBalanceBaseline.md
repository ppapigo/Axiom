# Axiom 스킬 밸런스 기준안

PvP 수치는 100을 기준으로 설계한다. 스킬 제작은 총 100P 안에서 구성하며,
강한 효과일수록 비용을 크게 올린다. 플레이 테스트 이후 각 수치는 ±10~20% 범위에서 조정한다.

## 기본 능력치

| 역할 | 체력 | 공격력 | 이동속도 |
|---|---:|---:|---:|
| 탱커 | 1400 | 80 | 95% |
| 전사 | 1200 | 100 | 100% |
| 암살자 | 900 | 115 | 110% |
| 원거리 | 950 | 110 | 100% |
| 마법사 | 900 | 115 | 100% |
| 서포터 | 1000 | 85 | 100% |

현재 프로토타입은 탱커, 암살자, 마법사를 사용한다. 전사, 원거리, 서포터는 역할 확장 기준으로 사용한다.

## 이동기

| 역할 | 거리 | 쿨타임 |
|---|---:|---:|
| 탱커 | 4m | 12초 |
| 전사 | 5m | 10초 |
| 암살자 | 8m | 5초 |
| 원거리 | 4m | 11초 |
| 마법사 | 4m | 12초 |
| 서포터 | 5m | 10초 |

## CC

| 효과 | 기준 수치 |
|---|---:|
| 둔화 | 30% / 2초 |
| 속박 | 1.5초 |
| 기절 | 1초 |
| 에어본 | 0.7초 |

## 기본 상태이상

| 상태이상 | 효과 |
|---|---|
| 화상 | 4초간 초당 공격력의 8% 피해 |
| 빙결 | 이동속도 30% 감소, 2초 |
| 감전 | 관통 피해 +20% |
| 독 | 5초간 초당 최대체력의 1% 피해 |
| 물 | 체력 10% 회복 |

## 속성 조합

| 조합 | 효과 |
|---|---|
| 불 + 물 | 추가 피해 25% |
| 물 + 얼음 | 속박 1.5초 + 추가 피해 15% |
| 물 + 번개 | 초당 6% 지속 피해 + 기절 0.5초 |
| 얼음 + 번개 | 방어력 20% 감소, 4초 |
| 불 + 독 | 화상 피해 50% 증가 |
| 불 + 얼음 | 추가 피해 35% |
| 바람 + 속성 | 주변 5m 확산 |
| 대지 + 속성 | 최대체력의 15% 보호막 + 적 공격력 15% 감소 |

## 패시브

| 패시브 | 기준 수치 |
|---|---|
| 스킬 적중 시 쿨타임 감소 | 1초 감소, 내부 쿨타임 2초 |
| 무적 | 1.5초, 내부 쿨타임 90초 |
| 피해 증가 | +10% |
| 추가 광역 피해 | 주변 4m, 공격력의 40% |
| 피격 시 체력 재생 | 5초간 초당 최대체력의 2% |
| CC 적중 시 보호막 | 최대체력의 12%, 내부 쿨타임 10초 |

## 궁극기

- 쿨타임: 60~90초
- 피해 계수: 250~350%
- CC: 최대 2초
- 범위: 일반 스킬보다 30~50% 넓게 설정

## 스킬 제작 포인트

총 100P를 사용한다.

| 항목 | 비용 |
|---|---:|
| 피해 10% 증가 | 5P |
| 범위 1m 증가 | 6P |
| 사거리 1m 증가 | 5P |
| 쿨타임 1초 감소 | 6P |
| 화상/독 부여 | 10P |
| 둔화 | 10P |
| 기절 | 20P |
| 에어본 | 18P |
| 이동기 추가 | 25P |
| 보호막 생성 | 15P |
| 회복 효과 | 15P |

## 구현 원칙

- 모든 수치와 비용은 ScriptableObject 및 Inspector에서 수정 가능해야 한다.
- CC 지속시간, 상태이상 수치, 속성 조합은 전투 코드와 분리된 데이터로 관리한다.
- 역할 제한과 최대 피해·범위 제한은 스킬 생성 결과 검증 단계에서 적용한다.
- 총 100P 초과 스킬은 저장 또는 전투 적용 전에 거부한다.
- 자연어 기반 스킬 생성은 이 기준 데이터를 읽고 `SkillDefinition`을 생성해야 한다.
